Tentang ApiWaspada

Pendukung Verifikasi Visual & Spasial Kebakaran

Dirancang untuk membantu menyaring laporan masyarakat melalui analisis citra otomatis sebelum ditindaklanjuti oleh petugas verifikasi di lapangan.

1. Deteksi Visual Api & Asap

Menggunakan arsitektur Ultralytics YOLO dengan transfer learning pada D-Fire Dataset untuk mengenali objek Fire (Api) dan Smoke (Asap) lengkap dengan bounding box serta confidence score.

2. Pelaporan Berbasis Lokasi (GIS)

Mengintegrasikan Browser Geolocation API dan peta interaktif Leaflet.js + OpenStreetMap untuk merekam koordinat latitude dan longitude lokasi dugaan kebakaran secara akurat di Kota Jambi.

3. Verifikasi & Audit Petugas

Setiap laporan yang masuk berstatus awal pending dan diperiksa oleh petugas melalui dashboard terproteksi untuk diperbarui menjadi verified, rejected, atau completed.

Alur Proses Terintegrasi

Bagaimana ApiWaspada Bekerja?

Empat tahapan terstruktur mulai dari pengunggahan bukti visual oleh masyarakat hingga pemantauan spasial oleh petugas.

1

Unggah Foto & Lokasi

Masyarakat mengambil foto dari kamera atau mengunggah file gambar (JPG/PNG), mengisi deskripsi kejadian, dan mengambil koordinat GPS.

2

Analisis AI YOLO

Backend FastAPI memproses citra menggunakan model YOLO untuk mendeteksi keberadaan api dan asap beserta bounding box dan skor keyakinan.

3

Penyimpanan & Kode Lacak

Data laporan dan citra hasil deteksi disimpan ke database SQLite. Pelapor memperoleh ID dan Kode Pelacakan unik (AW-...).

4

Verifikasi Dashboard & Peta

Petugas memeriksa bukti visual dan titik lokasi pada peta dashboard, memperbarui status laporan, dan mencatat riwayat penanganan.
